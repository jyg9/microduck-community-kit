串口连接

连接后所有 API 操作共用同一串口。HLS 出厂默认为 1 Mbps、ID 1； 如果之前改过波特率/ID，可先使用“自动探测 ID1”或逐个扫描。

Ping / ID 扫描

尚未扫描。默认全总线 0~253（每个无应答 ID 等 40 ms，约 10 秒）；只关心低 ID 时可把结束 ID 改小。

快速上手

  1. 确认舵机供电，串口设备为 /dev/ttyACM1，默认波特率先选 1 Mbps。
  2. 点击 连接，再点击 Ping；如果失败，依次尝试 115200、500000、250000、57600、38400。
  3. 到 实时反馈 读取当前位置、速度、电压、温度等状态。
  4. 到 位置控制 先打开扭矩，再写目标位置。
舵机运行时注意机械安全：初始测试建议使用较低的加速度/速度/电流，并确保有可断开电源的方式。

运行模式与扭矩

注意：写目标位置会被固件自动打开扭矩（实测本机行为）。 要彻底卸力，请在最后一次位置写入之后再点“关闭扭矩”。

位置相关设置

“中位校准”会关闭扭矩、关闭写入锁并执行 CAL 指令，把当前位置写为位置偏移中点。请先固定好机械零位。

运行模式说明：0 位置伺服 / 1 恒速 / 2 恒流 / 3 PWM 开环。模式切换本质是写 33 号寄存器。

内存表参数配置

读取/写入按内存表字段自动编码；只读字段不能写。修改 EPROM（5~39）前建议先关闭扭矩并按需关闭写入锁。
