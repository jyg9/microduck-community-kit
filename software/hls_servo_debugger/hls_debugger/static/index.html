串口连接

连接后所有 API 操作共用同一串口。HLS 出厂默认为 1 Mbps、ID 1； 如果之前改过波特率/ID，可先使用“自动探测 ID1”或逐个扫描。

Ping / ID 扫描

尚未扫描。默认全总线 0~253（每个无应答 ID 等 40 ms，约 10 秒）；只关心低 ID 时可把结束 ID 改小。

快速上手

  1. 确认舵机供电，串口设备为 /dev/ttyACM1（核心板上是 /dev/ttyS2，服务端用 --serial 指定），默认波特率先选 1 Mbps。
  2. 点击 连接，再点击 Ping；如果失败，依次尝试 115200、500000、250000、57600、38400。
  3. 整机 15 台舵机按关节 ID 编号：打开 舵机初始化 页签，按提示逐个接入新舵机。
  4. 到 实时反馈 读取当前位置、速度、电压、温度等状态。
  5. 到 位置控制 先打开扭矩，再写目标位置。
舵机运行时注意机械安全：初始测试建议使用较低的加速度/速度/电流，并确保有可断开电源的方式。

整机 15 台舵机初始化（编号 + 初始位置校准）

关节表、关节 ID 与 home 姿态角取自机器人软件 microduck_feetech/duck-control/src/model.rs 与 duck-ipc-proto 的 JOINT_NAMES。 新舵机出厂是 ID 1 / 1 Mbps，本向导把它改写成对应的关节 ID， 再按选择的工艺做初始位置校准，最后回读校验并上锁。
一次只接一个新舵机。两颗出厂 ID 都是 1 的舵机同时在线时会被一起改名， 产生重复 ID（重复 ID 会让整条总线的读写互相打架，且很难查）。 初始化会写 EPROM（ID / 波特率 / 应答级别 / 位置偏移）并可能让舵机转动， 请先确认机械安全、可以随时断电。
在线 本页已完成初始化/校准 未检测 / 无应答 列表按 ID 升序排列；“点检 15 台”或“检测总线”之后， 在线的舵机点亮黄色，本页已经完成初始化的关节显示绿色。

实测本机：Kp = 200 会让关节自激振荡——目标不动时电流 5 A、壳温升到 74 °C 并持续上升、人耳听到剧烈抖动；改成厂商默认的 32 后峰值电流 110 mA、温度不升。200 是 robotd 那份给 XL330（0..16383 标度） 调的 gain，在飞特 0..254 上是顶格。这里同时写 EEPROM 21/22 （掉电保存）与 RAM 50/51（立即生效）。注意：robotd 启动后会按 robotd.toml 的 gain 覆盖 RAM 50，两边要一致。
实测本机：出厂 11 号 = 4095 把位置字段锁在一圈 0..4095 内， 写负数目标位置会被夹到 0。而整机现在按单圈跑：关节角零点在 2048 计数、方向 −1，所以负的关节角在字段里表现为 2048 以上 的计数（left_hip_pitch 的 −299 → 2347），不需要负值、也就不需要多圈。 本开关默认关闭，整机就是这个配置；打开（9/11 号写 0/0）只在台面上 要转到一圈以外、或要写有符号绝对值时才需要，代价是固件不再限制行程。 注意两个方向都会真的写寄存器：取消勾选是把 9/11 号写回 0/4095，不是「跳过不写」，所以对一台已经开过多圈的舵机同样有效。
19 号是 EPROM 位域：BIT0 电压、BIT1 磁编码、BIT2 过热、BIT3 过流， 置 1 表示触发时舵机卸载（不再输出扭矩）。工具只按读改写动 BIT0/BIT3，BIT1/BIT2 保持舵机原值（实测本机 16 台都是 19 = 4，即出厂只开了过热保护）。 两项默认都不打开：关节中途卸力就是摔倒，这个取舍按使用场景自己定。

位置相关设置

中位校准结果将显示在这里。
“中位校准”会关闭扭矩、关闭写入锁并执行 CAL 指令，把当前位置写为位置偏移中点。 CAL 写的是 31 号位置偏移（EPROM 字段），而写入锁打开（55 号 = 1）时 EPROM 写入掉电不保存，所以解锁（55 号 = 0）是这一步的必要前提。 勾选上面这一项会在 CAL 之后补写 55 号 = 1，把舵机恢复成「EPROM 掉电不保存」 的保护状态，不留一颗没上锁的舵机（CAL 本身已经写完并保存，上锁不会撤销它）； 取消勾选则保持解锁，方便连续做多次 CAL / 偏移调试。请先固定好机械零位。
